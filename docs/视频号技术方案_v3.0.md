# 穿越圈视频号功能 — 技术方案 v3.0（极简版）

## 一、核心功能范围

| # | 功能 | 说明 |
|---|------|------|
| 1 | 视频流上下滑动播放 | 全屏 swiper + video，类抖音/视频号 |
| 2 | 点赞 | 用户可以点赞视频，双击爱心动画 |
| 3 | AI角色评论 | 只有古人互相评论，用户不能评论 |
| 4 | 视频号主页 | 每个古人一个视频号，查看其所有作品 |
| 5 | 关注 / 取消关注 | 用户可以关注古人视频号 |
| 6 | 管理员上传页 | 上传视频 + 管理视频号 |
| 7 | 人物详情关联 | 兰台人物详情页显示视频号入口 |

## 已删除的功能（全部砍掉）

❌ 用户评论 / 回复
❌ 收藏功能
❌ 搜索视频/视频号
❌ 播放量防刷机制
❌ videoSecCheck 视频审核
❌ 分享到朋友圈 + 海报
❌ swiper 三窗口优化
❌ 视频草稿 / 审核 / 拒绝状态

## 三、AI 评论机制

### 谁能评论？
只有与视频发布者「有关联关系」的历史角色，才能评论该视频。

### 评论内容来源
MVP 方案：预置种子评论数据 + 管理员上传时手工添加 AI 评论。

## 四、云函数设计

### 云函数名：`videoChannel`

#### 公共接口
- `feedList` — 视频流列表（游标分页）
- `videoDetail` — 视频详情
- `commentList` — 评论列表
- `channelDetail` — 视频号详情
- `channelVideos` — 视频号作品列表

#### 用户接口（需登录）
- `toggleLike` — 点赞 / 取消点赞
- `likeStatus` — 查询点赞状态
- `toggleFollow` — 关注 / 取消关注
- `followStatus` — 查询关注状态
- `followedChannels` — 我关注的视频号
- `increaseView` — 播放量 +1

#### 管理员接口（需 admin 权限）
- `adminChannelCreate` — 创建视频号
- `adminChannelUpdate` — 更新视频号信息
- `adminChannelList` — 视频号列表
- `adminVideoCreate` — 发布视频
- `adminVideoUpdate` — 更新视频信息
- `adminVideoRemove` — 删除视频（软删除）
- `adminVideoList` — 视频列表
- `adminCommentAdd` — 添加AI评论
- `adminCommentRemove` — 删除评论
