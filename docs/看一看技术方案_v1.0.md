# 穿越圈「看一看」功能 — 产品技术方案 v1.0

> 制定日期：2026-07-26
> 所属项目：timeslip-mini（微信小程序）

## 一、产品定位

### 1.1 功能概述

「看一看」是发现页的内容消费模块，核心是**历史评价、观点与科普文章**，以"真实的XX"为内容主线，为用户提供**知识性、观点性**的历史内容阅读体验。

### 1.2 与现有模块的区隔

| 模块 | 内容性质 | 互动方式 | 情绪定位 |
|------|----------|----------|----------|
| 朋友圈 | 古人发的社交媒体（虚构娱乐） | 点赞/评论 | 轻松有趣 |
| 视频号 | 古人发的短视频（虚构娱乐） | 点赞/关注 | 视觉刺激 |
| 雁书 | 写信给古人（AI 互动） | 写信/收信 | 情感连接 |
| 批一批 | 批奏折决策（AI 互动） | 决策/推演 | 角色扮演 |
| **看一看** | **历史评价/观点/科普文章（知识内容）** | **阅读/收藏/讨论** | **求知思考** |

### 1.3 目标用户

- 对历史感兴趣但缺乏系统了解的普通用户
- 喜欢看"历史真相""冷知识"类内容的用户
- 想从娱乐内容（朋友圈/视频号）过渡到深度内容的用户

## 二、内容设计

### 2.1 内容分类

| 分类 | 说明 | 示例 |
|------|------|------|
| **人物真相** | 揭秘历史人物的真实面貌，破除刻板印象 | 真实的孔子：不是文弱书生，是九尺六寸的山东大汉 |
| **史观解读** | 对历史事件的多角度分析 | 鸿门宴：项羽不杀刘邦，真的是妇人之仁吗？ |
| **冷知识** | 短篇历史趣味科普 | 古人用什么擦屁股？— 唐以前用竹片，宋以后有草纸 |
| **古今对照** | 古代制度/生活与现代的对照 | 唐朝的科举 vs 现在的公务员考试 |
| **史书勘误** | 纠正常见的历史误区 | 关羽的兵器真的是青龙偃月刀吗？正史记载是矛 |

### 2.2 内容形态

文章支持以下内容元素：

```
- 标题 + 副标题
- 封面图
- 正文（富文本：段落/引用/列表/加粗）
- 历史人物关联（插入人物卡片）
- 原典引用（文言文 + 译文）
- 历史时间线
- 总结观点
- 互动投票（文末）
```

### 2.4 内容生产方式

| 方式 | 说明 | 占比 |
|------|------|------|
| **预生成** | 编辑团队/历史顾问撰写，存入云数据库 | 80% |
| **AI 辅助生成** | 管理员通过 AI 辅助生成初稿，人工审核后发布 | 20% |

> 与朋友圈/视频号一致，采用**预生成优先**策略，减少运行时 AI 调用。

### 3.4 文章内容渲染方案

采用 **JSON 结构 + 前端组件化渲染**（非 Markdown），理由：

| 方案 | 优点 | 缺点 |
|------|------|------|
| Markdown 渲染 | 通用，复用 wd-markdown | 无法嵌入人物卡片/时间线/投票等交互组件 |
| **JSON 结构 + 组件渲染** | **支持富交互组件，内容结构化** | 需自研渲染逻辑 |

渲染逻辑：

```javascript
// 根据 content 数组中每个块的 type 渲染对应组件
content.forEach(block => {
  switch (block.type) {
    case 'paragraph':    // 段落
    case 'heading':      // 小标题
    case 'quote_origin': // 原典引用
    case 'figure_card':  // 人物卡片
    case 'timeline':     // 时间线
    case 'poll':         // 投票
  }
})
```

### 5.2 核心接口实现

#### articleList — 文章列表

```javascript
async function articleList(event) {
  const { category = 'all', page = 0, pageSize = 10 } = event
  const db = cloud.database()
  const _ = db.command

  let query = db.collection('articles').where({ status: 'published' })
  if (category !== 'all') {
    query = query.where({ category, status: 'published' })
  }

  const count = await query.count()
  const list = await query
    .orderBy('sortOrder', 'desc')
    .orderBy('createdAt', 'desc')
    .skip(page * pageSize)
    .limit(pageSize)
    .field({
      title: true, subtitle: true, coverImage: true,
      category: true, dynasty: true, summary: true,
      viewCount: true, likeCount: true, bookmarkCount: true,
      commentCount: true, tags: true, author: true, createdAt: true
    })
    .get()

  return {
    list: list.data,
    total: count.total,
    hasMore: (page + 1) * pageSize < count.total
  }
}
```

#### articleDetail — 文章详情

```javascript
async function articleDetail(event) {
  const { articleId } = event
  const db = cloud.database()

  const res = await db.collection('articles').doc(articleId).get()
  const article = res.data

  // 并行：增加阅读量 + 查询用户状态
  const openid = cloud.getWXContext().OPENID
  const [likeRes, bookmarkRes] = await Promise.all([
    db.collection('article_likes')
      .where({ articleId, _openid: openid }).count(),
    db.collection('article_bookmarks')
      .where({ articleId, _openid: openid }).count()
  ])

  return {
    article,
    liked: likeRes.total > 0,
    bookmarked: bookmarkRes.total > 0
  }
}
```

### 7.2 文章详情页（pages/discover/look/detail）

```javascript
// pages/discover/look/detail.js
const { requestCloud } = require('../../../utils/cloudRequest')
const { getDynastyInfo } = require('../../../utils/date')
const loginGuard = require('../../../utils/loginGuard')
const { throttle } = require('../../../utils/helpers')

const CATEGORY_NAMES = {
  figure_truth: '人物真相',
  perspective: '史观解读',
  fun_fact: '冷知识',
  compare: '古今对照',
  correction: '史书勘误'
}

Page({
  data: {
    articleId: '',
    article: null,
    content: [],
    liked: false,
    bookmarked: false,
    loading: true,
    readProgress: 0,
    relatedArticles: [],
    pollVoted: false,
    pollResults: []
  },

  onLoad(options) {
    if (options.id) {
      this.setData({ articleId: options.id })
      this.loadDetail(options.id)
    }
  },

  async loadDetail(id) {
    try {
      const data = await requestCloud('look', 'articleDetail', { articleId: id })
      if (!data || !data.article) {
        wx.showToast({ title: '文章不存在', icon: 'none' })
        return
      }

      const article = data.article
      article.categoryName = CATEGORY_NAMES[article.category] || article.category
      article.dynastyInfo = getDynastyInfo(article.dynasty)
      article.viewText = this.formatCount(article.viewCount)
      article.likeText = this.formatCount(article.likeCount)

      // 预加载人物卡片信息
      const content = await this.enrichContent(article.content || [])

      this.setData({
        article,
        content,
        liked: data.liked,
        bookmarked: data.bookmarked,
        loading: false
      })

      // 阅读量 +1
      requestCloud('look', 'increaseView', { articleId: id }, { throwError: false })

      // 加载相关文章
      this.loadRelated(id)
    } catch (e) {
      this.setData({ loading: false })
      wx.showToast({ title: '加载失败', icon: 'none' })
    }
  },

  async enrichContent(content) {
    const figureIds = content
      .filter(b => b.type === 'figure_card')
      .map(b => b.figureId)

    const figureMap = {}
    if (figureIds.length) {
      try {
        const data = await requestCloud('shiji', 'figuresBatch', { ids: figureIds }, { throwError: false })
        if (data && data.figures) {
          data.figures.forEach(f => {
            f.dynastyInfo = getDynastyInfo(f.dynasty)
            figureMap[f._id] = f
          })
        }
      } catch (e) {}
    }

    return content.map(block => {
      if (block.type === 'figure_card' && figureMap[block.figureId]) {
        block.figureInfo = figureMap[block.figureId]
      }
      return block
    })
  },

  async loadRelated(id) {
    try {
      const data = await requestCloud('look', 'relatedArticles', { articleId: id, limit: 3 }, { throwError: false })
      if (data && data.list) {
        const related = data.list.map(a => ({
          ...a,
          categoryName: CATEGORY_NAMES[a.category] || a.category
        }))
        this.setData({ relatedArticles: related })
      }
    } catch (e) {}
  },

  onPageScroll(e) {
    const scrollTop = e.scrollTop
    const query = wx.createSelectorQuery()
    query.select('.article-body').boundingClientRect()
      .selectViewport().scrollOffset()
      .exec(res => {
        if (res[0] && res[1]) {
          const total = res[0].height - this.data.windowHeight || 600
          const progress = Math.min(100, (res[1].scrollTop / total) * 100)
          if (Math.abs(progress - this.data.readProgress) > 2) {
            this.setData({ readProgress: progress })
          }
        }
      })
  },

  _onLike: null,
  onLike(e) {
    if (!loginGuard.checkLogin(this)) return
    if (!this._onLike) this._onLike = throttle(this.handleLike.bind(this), 300)
    this._onLike(e)
  },

  async handleLike() {
    const nowLiked = !this.data.liked
    const article = this.data.article
    article.likeCount = (article.likeCount || 0) + (nowLiked ? 1 : -1)
    article.likeText = this.formatCount(article.likeCount)

    this.setData({ liked: nowLiked, article })

    try {
      await requestCloud('look', 'toggleLike', { articleId: this.data.articleId }, { throwError: false })
    } catch (e) {}
  },

  async onBookmark() {
    if (!loginGuard.checkLogin(this)) return
    const nowBookmarked = !this.data.bookmarked
    this.setData({ bookmarked: nowBookmarked })
    wx.showToast({ title: nowBookmarked ? '已收藏' : '已取消收藏', icon: 'none' })

    try {
      await requestCloud('look', 'toggleBookmark', { articleId: this.data.articleId }, { throwError: false })
    } catch (e) {}
  },

  async onVote(e) {
    if (!loginGuard.checkLogin(this)) return
    const { index } = e.currentTarget.dataset
    if (this.data.pollVoted) return

    try {
      const data = await requestCloud('look', 'vote', {
        articleId: this.data.articleId,
        optionIndex: index
      }, { throwError: false })

      if (data && data.results) {
        this.setData({ pollVoted: true, pollResults: data.results })
      }
    } catch (e) {}
  },

  onFigureTap(e) {
    const { id } = e.currentTarget.dataset
    wx.navigateTo({ url: `/pages/lantai/figure-detail?id=${id}` })
  },

  openRelated(e) {
    const { id } = e.currentTarget.dataset
    wx.redirectTo({ url: `/pages/discover/look/detail?id=${id}` })
  },

  onShareAppMessage() {
    const a = this.data.article || {}
    return {
      title: a.title || '穿越圈·看一看',
      path: `/pages/discover/look/detail?id=${this.data.articleId}`,
      imageUrl: a.coverImage || ''
    }
  },

  formatCount(num) {
    const n = Number(num) || 0
    if (n >= 10000) return (n / 10000).toFixed(1) + 'w'
    if (n >= 1000) return (n / 1000).toFixed(1) + 'k'
    return String(n)
  }
})
```
